# GUI de 2048

Incremento local del 2026-10-01, build `unity-2048-005`.

La partida muestra únicamente el tablero y el puntaje acumulado. Fondo claro GPT
v2, fichas GPT v3 y números Inter con un atlas TextMeshPro estático. Los originales
y sus `.meta` permanecen; prompts y referencias están en `games/2048/ART-PROVENANCE.json`.
El material RoundedArtwork utiliza el interior del recurso y una silueta redondeada
suave para evitar que la transparencia y los bordes del PNG ensucien las casillas.

La plataforma ofrece Iniciar partida y Nueva partida para práctica; Unity no tiene
menús, marca, botones de dirección ni reinicio propio. El inicio competitivo sigue
siendo explícito, usa la sesión existente y no ofrece reiniciar. Tiempo, errores y
fin de partida se muestran en el host. El puntaje tiene una alternativa accesible
en HTML, sin duplicarlo visualmente. El modo ampliado conserva salida visible.

Flechas/WASD y arrastre comparten el mismo envío de dirección. La presentación desliza
las fichas hacia su destino, resalta las fusiones, hace aparecer la ficha nueva y
muestra brevemente los puntos ganados. La animación espera al estado confirmado,
comprueba correspondencia con el tablero anterior y nunca envía ni calcula una
puntuación competitiva. Notificaciones de reloj/bloqueo no repiten la animación;
una nueva partida cancela los efectos. Movimiento reducido los omite.

La build usa el proyecto Unity existente y su escena, sin regenerarla. Para repetir
las comprobaciones: `npm run games:build:2048`, `npm test`, `npx tsc --noEmit`.
`npm run dev:games` sirve la revisión aislada en `http://127.0.0.1:3080/play`.
No modifica Supabase, Flow ni despliegues. El contenedor local de 3081 requiere su
propio empaquetado; esta entrega no lo reemplaza ni publica a producción.

La evidencia de ejecución está en `2048-GUI-EVIDENCE.json`; capturas y logs locales
en `artifacts/unity-2048`. La revisión de viewport móvil y las pruebas de pointer
no equivalen a prueba en teléfono físico. Aceptación visual humana pendiente.
